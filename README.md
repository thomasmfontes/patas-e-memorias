# Patas & Memórias 🐾

Um memorial digital carinhoso e eterno para celebrar e preservar as lembranças mais queridas do seu pet.

## 🌟 Funcionalidades

- **Mural de Histórias e Momentos:** Registre lembranças com fotos, títulos, datas e histórias detalhadas.
- **Álbum Fotográfico / Galeria:** Visualização em grade e lightbox para rever cada fotografia em tela cheia.
- **Filtros por Categoria e Favoritos:** Organize por categorias (Filhote, Brincadeiras, Viagens, Dia a Dia, Soneca, Família) e destaque momentos especiais com o coração.
- **Perfil do Companheiro:** Dados personalizados com anos de vida, subtítulo e epitáfio.
- **Sincronização em Tempo Real:** Conectado ao Firebase Cloud Firestore com persistência instantânea.
- **Responsivo e PWA Ready:** Experiência moderna e fluida para celulares e computadores.

## 🚀 Tecnologias

- **Vite**
- **JavaScript (ES Modules)**
- **CSS3 Moderno**
- **Firebase Firestore & Authentication**

## 📦 Como rodar localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
